# 🌐 FeedMe Promotional Showcase Website (`feedme-website`)

Next.js 16 Marketing & Showcase Website for the **FeedMe** All-in-One Health & Fitness ecosystem. Built with a modern, distraction-free health-tech aesthetic inspired by Apple Fitness+, Whoop, and "AI เปลี่ยนชีวิตการออกกำลังกายของผม" (ลงทุนDiary).

---

## 🌟 Key Features

1. **Modern Health-Tech Showcase:** Hero section highlighting the ecosystem's 3 pillars (IoT Scale, AI Food Vision, and AI Progressive Overload Workout Coach).
2. **Prominent Call-To-Action (CTA):** "Launch Web App" linking directly to the core Cross-Platform Web App (`http://localhost:8081` or configurable `NEXT_PUBLIC_APP_URL`).
3. **Interactive Live Mockup:** Real-time preview card demonstrating Net Energy Balance, Simulated IoT Scale readings, and AI Workout insights.
4. **Product Philosophy:** Showcases the "System Over Willpower" framework and habit gamification loop.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16.2 (App Router)
- **UI Library:** React 19.2, Tailwind CSS v4
- **Charts:** Recharts 3.10
- **Theme:** Warm Obsidian Dark Mode (`#111110`)

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```
